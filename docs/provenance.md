## Upstream preprocessing pipeline

The included Japan input was generated by a local snapshot of the separate [Population Project](https://github.com/JS2570/Population-Project). The source snapshot reported Git commit:

```text
1e39c2bcd482576477511dff7a1ea77defec7875
```

The generated `data/processed/data120/hmd.csv` was not itself tracked by upstream Git. Its local source checksum was:

```text
e505b181104b821a6a8a9a4861b2c986e766af47e516193d3070d685fd351b15
```

The repository input was created by selecting `ISO3 == JPN` and `Year == 2010`, then retaining only `ISO3`, `Year`, `Age`, and `lx`. No imputation, smoothing, rescaling, or numerical transformation was applied during extraction.

The upstream pipeline is referenced rather than merged. None of its acquisition credentials, downloader code, Shiny interface, Python/R processing code, or other generated tables are copied into this repository.

## Restricted workbooks

The Hadza and Aché workbooks remain local inputs. Their contents are neither copied nor represented by derived values in this repository. Only the filenames and schema expected by the preserved MCMC loader are documented.
